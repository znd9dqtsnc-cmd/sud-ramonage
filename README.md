# SUD RAMONAGE

Site statique Astro prêt pour GitHub et Vercel.

## Commandes

```bash
npm install
npm run build
```

Vercel : Framework **Astro**, commande d’installation `npm install`, commande de build `npm run build`, dossier de sortie `dist`.

## Contenus centralisés

Les coordonnées, zones, prestations et tarifs sont regroupés dans `src/data/company.js` afin d’éviter les incohérences lors des évolutions.

## Avant publication

Voir les marqueurs « À compléter » dans les mentions légales, les CGV et la politique de confidentialité. En particulier : adhésion à un médiateur de la consommation, politique de conservation, modalités de paiement/annulation et coordonnées légales actualisées de l’hébergeur.
